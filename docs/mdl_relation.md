# 本模型与 Kirkley MDL 的关系（C 的推导笔记）

结论先行：**Kirkley 加权 ER 编码的描述长度，恰好等于一个贝叶斯枢纽模型的负对数边际似然。在这个模型里，同组球员的个人速率服从形状参数 α = N 的 Gamma 分布。** CM 编码则是枢纽组取 α = 1、非枢纽组取 α = N。原方案的泊松模型是 α → ∞ 的极限。本项目的模型把 α 当作需要从数据估计的参数，再加上上场时间和位置分组。`tests/test_mdl_relation.py` 在 50 个随机度序列上验证了这个恒等式，误差 < 10⁻⁷。

## 1. 记号

N 个节点，加权出度（传球数）为 k_i，总数 M = Σk_i。H 是枢纽集合，|H| = h；G ∈ {H, H̄} 表示枢纽组和非枢纽组，K_G 是组内度数之和。MS(n, k) = C(n+k−1, k) 是可重复组合数。

Kirkley（PRE 109, 034310）加权编码的描述长度如下，hubs 取度数最大的 h 个节点：

- ER：L_ER(h) = log N + log M + log C(N,h) + log MS(hN, K_H) + log MS((N−h)N, K_H̄)
- CM：L_CM(h) = log N + log M + log C(N,h) + log MS(h, K_H) + Σ_{i∈H} log MS(N, k_i) + log MS((N−h)N, K_H̄)

## 2. 一个分解

对 g 个节点、每个节点有 N 个可能目标的多重图，有以下恒等式：

log MS(gN, K) = −log DirMult(k_G | K; α = N) + Σ_{i∈G} log MS(N, k_i)

其中 DirMult(k | K; α) = K! Γ(gα)/Γ(K+gα) · Π_i Γ(k_i+α)/(k_i! Γ(α))，是 Dirichlet–多项分布。证明思路：先在 gN 个格子上按多重集计数，再按节点分组。每个节点的 N 个格子合起来，相当于一个参数为 N 的 Dirichlet 分量；用 Gamma 函数写出两边，即可逐项相等。

右边的 Σ log MS(N, k_i) 对所有节点求和，与 H 怎么选无关。因此：

- **L_ER(h) = log N + log M + log C(N,h) − log DirMult(k_H | K_H; N) − log DirMult(k_H̄ | K_H̄; N) + 常数**
- **L_CM(h) = log N + log M + log C(N,h) − log DirMult(k_H | K_H; 1) − log DirMult(k_H̄ | K_H̄; N) + 常数**

CM 的枢纽项 log MS(h, K_H) 正好等于 −log DirMult(k_H | K_H; 1)。

## 3. 对应的贝叶斯模型

设每个节点的计数 k_i ~ Poisson(T λ_G u_i)，其中个人倍数 u_i ~ Gamma(α, α) 独立同分布，组速率 λ_G 取任意先验，两组的 λ 相互独立。给定组内总数 K_G 时，组内的分配恰好服从 DirMult(α)：同尺度的独立 Gamma 变量归一化后服从 Dirichlet 分布，且与 λ_G 无关。于是：

−log p(k | H) = −log P(H) − Σ_G log p(K_G) − Σ_G log DirMult(k_G | K_G; α)

逐项对应如下：

| Kirkley 编码 | 贝叶斯模型 |
|---|---|
| log N + log C(N,h)：编码枢纽个数和名单 | −log P(H)：本项目取 log(s_max+1) + log C(N,h) |
| log M：编码两组各自的总数 | −Σ log p(K_G)：组总数的边际分布（λ 先验的奥卡姆因子） |
| ER 的 log MS 数据项 | DirMult(α = N)：同组个人速率的变异系数为 1/√N |
| CM 的枢纽项 | 枢纽组取 DirMult(α = 1)，即每个枢纽的度数单独编码 |
| ——（无对应） | α → ∞ 时为多项分布，也就是原方案的泊松模型 |

**命题**：设所有节点暴露时间相同、只有一个位置组，枢纽组与非枢纽组的速率 λ_G 各自独立，且先验为 Gamma(a = 1, b)、b → 0（即平坦先验）。此时给定 M，枢纽组总数 K_H 在 {0, …, M} 上均匀分布，所以 −log p(K_H | M) = log(M+1)。在"度数最大的前 h 个"这个扫描范围内，对每个 h 都有：

−log p(k, H) = L_ER(h) + log((M+1)/M) + 常数，其中取 α = N，P(H) = 1/(N·C(N,h))。

因此 Kirkley ER 编码选出的 h，就是该贝叶斯模型的最大后验枢纽个数（log M 与 log(M+1) 之差与 h 无关）。CM 编码同理，只需把枢纽组改为 α = 1。

两点不同：Kirkley 只扫描度数最大的前 h 个节点，贝叶斯模型则对所有组合求和；Kirkley 的 h 取 1…N，并以"没有枢纽"作为单独的基线编码。

## 4. 这个对应说明了什么

1. **MDL-ER 隐含地假设同组节点速率的变异系数为 1/√N。** 本项目 N ≈ 20，对应的变异系数约 0.22，与 2015/16 西甲实测的中场 0.23、前锋 0.26 相近，但比后卫的 0.12 大。所以 MDL 在"多少差异算正常"这个问题上，用的是一个由节点数决定、与数据无关的数字。
2. **原方案的泊松模型对应 α → ∞，即假设同组球员完全一样。** 赛季总数很大（组织层每人上千次传球），任何风格差异都会被判为核心，这正是 E1、E4、E5 里它几乎总报 3 个核心的原因。用 Stirling 近似：对固定的经验比例，DirMult(α) 的代码长度随 K 只按 log K 增长，多项分布的代码长度则按 K·KL(经验分布 ‖ 均匀分布) 线性增长。计数越大，两者差得越多。
3. **本项目的模型把 α 当作参数，从联盟数据估计（经验贝叶斯），再加上上场时间 T_i 和位置分组 g(i)。** Kirkley 的方法里没有这两项：MDL 在暴露时间不等时只能先按分钟折算再取整（即 MDL-min 版本）。另外，核心倍数 ρ 相当于度修正 SBM（第 5 讲）里节点度参数的一个离散化版本：问的是某人的度参数是否显著偏离同组常态。
