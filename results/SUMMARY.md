# 第一版结果总结（2026-11-07）

全部由 `make data calib sim real figs` 产出。数字来自 `results/*.json`，详表见 `results/tables.md`，图见 `figures/`。

## 一、和原方案不同的地方（需要全组确认）

1. **主模型改为"加入个体差异"的版本。** 2015/16 数据显示，同队同位置组的球员之间存在稳定的风格差异：组织层赛季总数的离散度是泊松预期的 14–34 倍，逐场过度离散 φ 只有 3.2。原方案的泊松模型（即使做了 φ 修正）因此几乎每队都报出 3 个核心：E5 中 20 队有 19 队报满 3 个；E1 无核心模拟中的误报率为 96–99%。新模型给每名球员一个风格倍数 u ~ Gamma(α_g, α_g)，α_g 用联盟数据做经验贝叶斯估计（`results/alpha.json`）。原模型保留，作为对照一起报告。
2. **威胁层也去掉了定位球**（`config.yaml` 中的 `box_layer_excludes_set_pieces`），理由与决定 3 相同。试跑的定义保留为 `is_box_pilot`，两者的差异见 `results/data_check.md`。
3. **E2 增加了 ρ = 3，以及"球员完全相同"这一对照世界。**

## 二、主要发现

**1. 方法层面（E1、E2、E6）**
- 无核心时的误报率（组织层，φ 和个体差异按实测）：本模型 4–6%；原泊松模型 96–99%；MDL-CM（按分钟折算）74–89%；均值 + 2SD 61–69%；传球数第一、每 90 分钟第一、PageRank 第一都是 100%（按定义总会报出一人）。
- 消融实验说明每一部分都有用：
  - 去掉上场分钟：只要轮换是真实的，误报率就变成 100%。
  - 去掉位置：前锋核心的检出率从 0.40 降到 0.04。
  - 不共享 ρ：误报率升到 19–24%。
- 检出率（ρ = 2，真实轮换）：本模型对中场核心为 0.50，对前锋核心为 0.40。排名类方法对中场核心更高（0.8–0.9），但代价是误报率 100%。
- **E2 的核心结论：个体差异是持久的，多看比赛也消除不了它。** 组织层 ρ = 2 的核心，看完 38 场检出率也只有约 50%；ρ = 3 时中场核心约 19 场、前锋核心约 38 场能达到"检出 80%、误报 ≤ 5%"。威胁层每场计数太少，ρ ≤ 3 时 38 场内都达不到。在"球员完全相同"的世界里，原泊松模型只需 5–8 场（ρ = 2）。
- E6 置换检验（真实数据，打乱同位置球员的身份）：本模型误报率为组织层 1.2%、威胁层 0.5%；原泊松模型为 15.5% 和 21%。

**2. 巴萨（E4，图 6、图 8）**
- **威胁核心：梅西。** 他是 2010/11、2011/12、2014/15、2015/16、2020/21 共 5 个赛季的最大后验核心，后验概率 0.61–0.83；2012/13、2016/17、2018/19、2019/20 在 0.5–0.65 之间；2008/09、2009/10、2013/14、2017/18 只有 0.1–0.2。从 2007/08 起，他传进禁区的次数每季都是全队第一，份额 19–33%。
- **组织层没有核心。** 哈维的每 90 分钟传球数（约 106）是巴萨其他中场的约 1.4 倍，但联盟里中场之间的正常差异约为 23%，所以他的入选概率只有 0.1–0.2。把位置细分成六类（中路中场单独成组）后结论不变。只有把个体差异人为减半（α × 2）时，他才会在一个赛季入选。
- 这与方案里"哈维应是组织核心（Buldú 2019）"这条常识检查不一致，见第四节。

**3. 西甲 2015/16（E5，图 7）**
- 本模型在组织层只认出 3 个核心：马竞的菲利佩·路易斯，后验概率 0.97，第 22 场起稳定在 0.9 以上；塞尔塔的丰塔斯和奥雷利亚纳。威胁层认出 3 个：梅西、塞尔塔的诺利托、塞维利亚的巴内加。
- MDL-CM（原始计数）一个都没报；MDL-ER 每队报出 10–20 人；MDL-CM（按分钟折算）在 14 队各报出 1–3 名组织型中场，例如克罗斯、帕雷霍、特拉肖拉斯。

**4. 前半季预测后半季（E3，表 2a）**
- 按每支球队平均，泊松模型的预测提升最大（组织层 1.55），因为它总是挑出 3 名速率最高的球员。
- 按每名入选球员平均，本模型最高：组织层 1.86、威胁层 1.97，泊松模型分别为 0.55 和 0.84，传球数第一为 0.24 和 0.96。也就是说，本模型报得少，但报出的人最可信。
- 饱和模型（每人一个独立速率）在组织层反而比"无核心"更差（−3.7）。这说明 E3 的指标会奖励"挑出速率高的人"，不能单独用来判断"有没有核心"。论文里要说明这一点。

**5. 理论（C，`docs/mdl_relation.md`）**
- Kirkley 的加权 ER 编码，等价于"同组个人差异参数 α = N"的贝叶斯枢纽模型；CM 编码是枢纽组取 α = 1、非枢纽组取 α = N。原方案的泊松模型是 α → ∞。本项目的模型把 α 交给数据估计，再加上上场时间和位置。该恒等式已用 `tests/test_mdl_relation.py` 数值验证，误差 < 10⁻⁷。
- 一个推论：MDL 隐含假设同组节点速率的变异系数为 1/√N ≈ 0.22（N ≈ 20），恰好与实测的中场、前锋差异相近。

**6. 敏感性（`results/tables.md` 末尾）**
- 结论对 ρ 先验上限（10）、先验形状、先验均值、最少分钟数、s_max、边锋归属都比较稳定。
- 对 α 最敏感：α × 0.5 时一个核心都不报，α × 2 时报出 23 个组织核心和 33 个威胁核心。
- ρ_max = 2 时梅西反而不入选：他的倍数约为 3，超出了先验上限，只能被解释成风格差异。
- 不做 φ 修正时，组织核心从 3 个增至 12 个。

## 四、需要全组讨论的问题

1. **主模型选哪个？** 我建议用加入个体差异的版本，原泊松模型作为"不考虑个体差异会怎样"的对照。证据：E1 的误报率、E6、E5 中报满 3 个的比例。
2. **哈维的问题怎么讲？** 有两种讲法：(a) 把它作为本文的发现，即哈维传得最多，但相对中场的正常风格差异并不算超出，"核心"取决于拿什么作比较基准；(b) 认为个体差异的估计偏大，因为三类位置分得太粗，并在讨论里说明。六类角色的敏感性分析支持 (a)。
3. **E3 的指标要换一种表述**，见第二节第 4 点：建议主报"每名入选球员的预测提升"和前后半季名单一致性。
4. 计划里"可做"一档的度修正 SBM 角色，现在有了更具体的动机：位置分得越细，α 越可信。
